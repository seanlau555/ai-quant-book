# 背景知識：中美量化市場差異

> A股和美股在交易規則、市場結構、數據可用性上有顯著差異。理解這些差異是開發跨市場策略的前提。

---

## 一、交易規則對比

| 規則 | A股 | 美股 | 港股 |
|-----|-----|-----|-----|
| 交易時間 | 9:30-11:30, 13:00-15:00 | 9:30-16:00 ET | 9:30-12:00, 13:00-16:00 |
| 結算制度 | T+1 | T+1（2024年5月起） | T+2 |
| 漲跌停 | ±10%（創業板±20%） | 無限制 | 無固定漲跌停（有VCM機制） |
| 賣空 | 融券（限制多） | 相對自由 | 僅限指定證券，禁止裸賣空 |
| 最小變動單位 | ¥0.01 | $0.01 | 動態（根據價格區間變化） |
| 交易單位 | 100股整數倍 | 1股 | 證券發行人決定（一手可能不同） |
| 盤前盤後 | 集合競價 | 有盤前盤後交易 | 市前成交時段 & 收市競價時段 |
| 主要費率 | 印花税 0.05%（賣出時） | 佣金極低或免傭 | 印花税 0.1%（買賣雙方） |

## 二、T+1 的策略影響

### 2.1 A股 T+1

**規則**：當日買入的股票，次日才能賣出

**影響**：
- 無法做日內波段
- 無法快速止損
- 隔夜風險無法規避

**應對策略**：
```python
# A股策略需要考慮隔夜持倉
def should_buy(signal, overnight_risk):
    if overnight_risk > threshold:
        return False  # 風險太高不建倉
    return signal > 0
```

### 2.2 美股日內交易

**規則**：
- Pattern Day Trader（PDT）規則
- 賬户 < $25,000：5個交易日內最多3次日內交易
- 賬户 ≥ $25,000：無限制
- *注：FINRA 已批准修改 PDT 規則，計劃將固定金額限制改為更靈活的風險邊際（等待 SEC 最終批准）*

**優勢**：
- 可做日內策略
- 快速止損
- 利用盤中波動

## 三、漲跌停製度

### 3.1 A股漲跌停

| 板塊 | 漲跌停幅度 |
|-----|-----------|
| 主板（滬深） | ±10% |
| 創業板 | ±20%（2020年8月起；上市前5日無限制） |
| 科創板 | ±20%（2019年7月起；上市前5日無限制） |
| 北交所 | ±30%（2021年11月起） |
| ST股 | ±5% |

### 3.2 港股波動調節機制 (VCM)

**規則**：
- 旨在緩解極端的盤中波動。
- 恒指/國指成分股：±10%（5分鐘內價格偏離）。
- 觸發後進入5分鐘冷靜期，只能在固定價格區間交易。

**影響**：
- 連續漲停/跌停導致無法成交
- 漲停板無法買入（流動性消失）
- 跌停板無法賣出（被動止損失效）

**策略考量**：
```python
# 漲跌停檢測
def is_limit_up(price, prev_close, limit=0.10):
    return price >= prev_close * (1 + limit - 0.001)

def is_limit_down(price, prev_close, limit=0.10):
    return price <= prev_close * (1 - limit + 0.001)
```

### 3.3 美股熔斷機制

**指數熔斷**：
- Level 1 (7%): 暫停15分鐘
- Level 2 (13%): 暫停15分鐘
- Level 3 (20%): 當日停止交易

**個股熔斷**（LULD）：
- 價格偏離過大時暫停5分鐘

## 四、賣空機制

### 4.1 A股融券

**限制**：
- 需要開通融資融券賬户
- 券源有限，熱門股難借
- 融券成本高（年化 8-10%）
- 部分股票禁止融券

**實際影響**：
- 做空策略難以實施
- 市場中性策略成本高
- 對沖手段有限

### 4.2 美股賣空

**流程**：
1. 借入股票
2. 賣出
3. 買回還券

**成本**：
- 借券費（0.3% - 50%+ 年化）
- 分紅補償

**Easy-to-Borrow vs Hard-to-Borrow**：
- 大盤股容易借
- 小盤股、熱門做空標的難借且貴

## 六、市場參與者結構

### 6.1 A股

| 參與者 | 佔比 | 特點 |
|-------|------|-----|
| 散户 | ~80%+ (成交量) | 短期交易、情緒驅動、持倉佔比約20% |
| 機構 | ~20% (成交量) | 公募、私募、險資、外資(佔比上升中) |

**影響**：
- 波動率高
- 動量效應明顯
- 情緒驅動價格偏離

### 6.2 美股

| 參與者 | 佔比 | 特點 |
|-------|------|-----|
| 機構 | ~70-80% | 養老金、共同基金、對沖基金、高頻交易(佔成交50%+) |
| 散户 | ~20-25% | 近年因 Robinhood 等上升，"抄底"意願強 |

**影響**：
- 相對理性
- 因子有效性更持久
- 被動投資佔比高

### 7.1 A股有效策略

## 八、技術實現差異

### 8.1 回測注意事項

**A股**：
```python
# A股回測必須考慮的因素
class ChinaBacktester:
    def __init__(self):
        self.t_plus_1 = True  # T+1 限制
        self.limit_up_down = 0.10  # 漲跌停
        self.min_lot = 100  # 最小交易單位

    def can_sell(self, position, trade_date):
        # 檢查是否滿足 T+1
        return position.buy_date < trade_date

    def check_tradeable(self, price, prev_close):
        # 檢查是否漲跌停
        if self.is_limit_up(price, prev_close):
            return False  # 漲停無法買入
        if self.is_limit_down(price, prev_close):
            return False  # 跌停無法賣出
        return True
```

**美股**：
```python
# 美股回測更簡單
class USBacktester:
    def __init__(self):
        self.t_plus_0 = True  # 可當日交易
        self.fractional_shares = True  # 可碎股
```

## 十、實踐建議

### 10.1 A股策略開發

1. **考慮 T+1**：策略週期至少隔夜
2. **處理漲跌停**：回測時剔除漲跌停日
3. **注意換手率**：A股換手率高，交易成本累積快
4. **關注政策風險**：政策對 A 股影響大

### 10.2 美股策略開發

1. **注意 PDT 規則**：小賬户限制日內交易
2. **考慮盤前盤後**：重大新聞常在盤前盤後發佈
3. **借券成本**：做空策略要考慮 Hard-to-Borrow 成本
4. **流動性分層**：大盤股和小盤股流動性差異大

### 10.3 跨市場策略

```python
# 市場規則配置
def get_market_rules(market):
```

> **核心原則**：不要直接將美股策略套用到 A 股，也不要反過來。每個市場都有獨特的規則和參與者結構，策略必須適應本地市場特性。
