# 背景：中美量化市場差異

> A 股（中國）與美股在交易規則、市場結構和數據可得性方面有顯著差異。理解這些差異，是開發跨市場策略的前提。

---

## 1. 交易規則比較

| 規則 | A 股（中國） | 美股 | 香港 |
|------|--------------|------|------|
| 交易時間 | 9:30-11:30, 13:00-15:00 | 9:30-16:00 ET | 9:30-12:00, 13:00-16:00 |
| 結算 | T+1 | T+1（自 2024 年 5 月起） | T+2 |
| 漲跌幅限制 | ±10%（創業板 ±20%） | 無限制 | 無固定限制（VCM 機制） |
| 沽空 | 融券（限制甚多） | 相對自由 | 僅限指定證券，禁止裸沽空 |
| 最小 tick | ¥0.01 | $0.01 | 動態（按價格區間而異） |
| 交易單位 | 100 股的倍數 | 1 股 | 由發行人設定（每手股數不同） |
| 盤前／盤後 | 集合競價 | 盤前／盤後交易 | 開市前時段及收市競價 |
| 主要費用 | 印花稅 0.05%（賣方） | 佣金極低或為零 | 印花稅 0.1%（雙邊） |

## 2. T+1 對策略的影響

### 2.1 中國 A 股 T+1

**規則**：今日買入的股票，只能於翌日賣出

**影響**：
- 不能做日內波段
- 不能快速 stop loss
- 不能規避隔夜風險

**策略應對**：
```python
# A-share strategies must consider overnight positions
def should_buy(signal, overnight_risk):
    if overnight_risk > threshold:
        return False  # Risk too high, don't open position
    return signal > 0
```

### 2.2 美股日內交易

**規則**：
- Pattern Day Trader（PDT）規則
- 帳戶 < $25,000：5 個交易日內最多 3 次日內交易
- 帳戶 ≥ $25,000：沒有限制
- *註：FINRA 已批准修改 PDT 規則，計劃以更靈活的風險保證金取代固定金額限制（有待 SEC 最終批准）*

**優勢**：
- 可以做日內策略
- 可快速 stop loss
- 可利用日內波動

## 3. 漲跌幅限制制度

### 3.1 A 股漲跌幅限制

| 板塊 | 漲跌幅限制範圍 |
|------|----------------|
| 主板（上交所／深交所） | ±10% |
| 創業板 | ±20%（自 2020 年 8 月起；上市首 5 日不設限） |
| 科創板 | ±20%（自 2019 年 7 月起；上市首 5 日不設限） |
| 北京證券交易所（北交所） | ±30%（自 2021 年 11 月起） |
| ST 股票 | ±5% |

### 3.2 香港波動調節機制（VCM）

**規則**：
- 旨在緩和日內極端波動。
- 恒指／國指成分股：±10%（5 分鐘價格偏離）。
- 觸發後，進入 5 分鐘冷靜期，以固定價格範圍交易。

**影響**：
- 連續漲停／跌停令訂單無法成交
- 漲停時買不到（liquidity 消失）
- 跌停時賣不出（被動 stop loss 失效）

**策略考慮**：
```python
# Price limit detection
def is_limit_up(price, prev_close, limit=0.10):
    return price >= prev_close * (1 + limit - 0.001)

def is_limit_down(price, prev_close, limit=0.10):
    return price <= prev_close * (1 - limit + 0.001)
```

### 3.3 美股熔斷機制

**指數熔斷**：
- 第一級（7%）：停牌 15 分鐘
- 第二級（13%）：停牌 15 分鐘
- 第三級（20%）：全日停止交易

**個股熔斷**（LULD）：
- 價格偏離過大時，停牌 5 分鐘

## 4. 沽空機制

### 4.1 A 股融券

**限制**：
- 必須開立融資融券帳戶
- 可供融券的證券有限，熱門股難以借到
- 借貸成本高（年化 8-10%）
- 部分股票禁止融券

**實際影響**：
- 沽空策略難以實施
- Market neutral 策略成本高昂
- Hedge 工具有限

### 4.2 美股沽空

**流程**：
1. 借入股票
2. 賣出
3. 買回並歸還

**成本**：
- 借股費用（年化 0.3% - 50%+）
- 股息補償

**Easy-to-Borrow 與 Hard-to-Borrow**：
- 大型股容易借入
- 小型股、熱門沽空對象難以借入且費用高昂

## 6. 市場參與者結構

### 6.1 A 股

| 參與者 | 佔比 | 特點 |
|--------|------|------|
| 散戶 | 約 80%+（成交量） | 短線交易、情緒驅動，持股佔比約 20% |
| 機構 | 約 20%（成交量） | 公募基金、私募基金、保險、外資（增長中） |

**影響**：
- 波動大
- Momentum 效應強
- 情緒驅動的價格偏離

### 6.2 美股

| 參與者 | 佔比 | 特點 |
|--------|------|------|
| 機構 | 約 70-80% | 退休基金、互惠基金、hedge fund、HFT（佔成交量 50%+） |
| 散戶 | 約 20-25% | 近年因 Robinhood 等而增加，有強烈的「逢低買入」傾向 |

**影響**：
- 相對理性
- Factor 的有效性更持久
- 被動投資佔比高

## 7. 策略差異

### 7.1 A 股有效的策略

| 策略 | 有效程度 | 原因 |
|------|----------|------|
| Momentum | 強 | 散戶羊群效應、漲停效應 |
| 小市值 | 強 | 殼價值、liquidity 溢價 |
| Reversal | 中等 | 過度反應後的修正 |
| Value | 弱至中等 | 散戶偏好增長股 |

### 7.2 美股有效的策略

| 策略 | 有效程度 | 原因 |
|------|----------|------|
| Value | 中等 | 長期有效但具週期性 |
| Momentum | 中等 | 被機構交易稀釋 |
| Quality | 強 | 長期穩定 |
| Low volatility | 強 | 經風險調整後回報良好 |

## 8. 技術實現差異

### 8.1 Backtest 的考慮因素

**A 股**：
```python
# Factors A-share backtesting must consider
class ChinaBacktester:
    def __init__(self):
        self.t_plus_1 = True  # T+1 restriction
        self.limit_up_down = 0.10  # Price limits
        self.min_lot = 100  # Minimum trading unit

    def can_sell(self, position, trade_date):
        # Check if T+1 is satisfied
        return position.buy_date < trade_date

    def check_tradeable(self, price, prev_close):
        # Check for price limits
        if self.is_limit_up(price, prev_close):
            return False  # Cannot buy at limit up
        if self.is_limit_down(price, prev_close):
            return False  # Cannot sell at limit down
        return True
```

**美股**：
```python
# US stock backtesting is simpler
class USBacktester:
    def __init__(self):
        self.t_plus_0 = True  # Can day trade
        self.fractional_shares = True  # Fractional shares allowed
```

## 9. 監管差異

### 9.1 A 股監管

- 中國證監會（CSRC）、上海及深圳交易所
- 程序化交易需要報備
- 嚴格監控異常交易

### 9.2 美股監管

## 10. 實用建議

### 10.1 A 股策略開發

1. **考慮 T+1**：策略週期至少為隔夜
2. **處理漲跌停**：backtest 時剔除漲停／跌停日
3. **留意 turnover**：A 股 turnover 高，交易成本累積很快
4. **留意政策風險**：政策對 A 股影響重大

### 10.2 美股策略開發

1. **留意 PDT 規則**：小額帳戶有日內交易限制
2. **考慮盤前／盤後**：重大消息常在盤前／盤後發布
3. **借股成本**：沽空策略必須考慮 Hard-to-Borrow 成本
4. **Liquidity 分層**：大型股與小型股的 liquidity 差異顯著

### 10.3 跨市場策略

```python
# Market rules configuration

    if market == 'CN':

            't_plus': 1,

```

---

> **核心原則**：不要將美股策略直接套用於 A 股，反之亦然。每個市場都有獨特的規則和參與者結構；策略必須適應當地市場的特性。
