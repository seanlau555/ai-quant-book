# 背景知識：歷史著名量化事故

> 歷史是最好的老師。這些事故告訴我們：再聰明的模型也會失敗，風控永遠是第一位。

## 一、LTCM 崩潰 (1998)

### 事件概述

**Long-Term Capital Management (LTCM)** 是由諾貝爾經濟學獎得主 Myron Scholes 和 Robert Merton 創立的對沖基金。

- **策略**：固定收益套利，利用債券價格的微小偏差
- **槓桿**：證券槓桿超過25倍，衍生品槓桿超過250:1
- **AUM**：初始47億美元，崩潰時資本已降至不足10億美元
- **敞口**：借入約1250億美元證券，持有1.25萬億美元衍生品名義價值

### 崩潰過程

1. **1998年8月**：俄羅斯債務違約，引發全球恐慌
2. **流動性危機**：所有人同時拋售風險資產
3. **相關性崩潰**：歷史上不相關的資產突然高度相關
4. **爆倉**：四個月內虧損**46億美元**，資本降至不足10億

### 教訓

| 問題 | 教訓 |
|-----|------|
| 過度槓桿 | 槓桿放大收益也放大風險 |
| 流動性假設 | "總能賣出"是危險假設 |
| 相關性假設 | 危機時相關性趨向於 1 |
| 模型過度自信 | 歷史數據不能預測黑天鵝 |

### 量化啓示

```
你的模型在正常市場表現好 ≠ 危機時還能存活
```

## 二、Knight Capital 閃崩 (2012)

### 事件概述

**Knight Capital** 是美國最大的做市商之一。

- **日期**：2012年8月1日
- **持續時間**：45分鐘（開盤後第一小時內）
- **虧損**：4.4億美元（公司淨資產的40%）
- **交易規模**：買入約**70億美元**的約150只股票

### 崩潰過程

1. **代碼部署錯誤**：新代碼激活了本應刪除的舊測試代碼
2. **瘋狂交易**：系統在約150只股票上執行數百萬筆錯誤交易
3. **無人察覺**：45分鐘內無法停止，不斷累積大量不需要的頭寸
4. **結果**：公司被迫出售，獲得4億美元緊急投資才避免破產

### 技術細節

- 舊代碼本應刪除，但被遺忘在生產環境
- 部署到 8 台服務器，但只有 7 台更新成功
- 1 台服務器運行舊代碼，觸發錯誤交易
- 沒有自動熔斷機制

### 教訓

| 問題 | 教訓 |
|-----|------|
| 代碼部署流程 | 必須有完整的回滾機制 |
| 監控缺失 | 異常交易必須實時告警 |
| 熔斷機制 | 必須有自動停止交易的機制 |
| 技術債務 | 舊代碼必須徹底清理 |

### 量化啓示

```
最大的風險往往來自技術故障，而不是市場
```

## 三、Flash Crash (2010)

### 事件概述

**2010年5月6日**，道瓊斯指數在幾分鐘內暴跌近 1000 點（約 9%），然後迅速反彈。

### 崩潰過程

1. **觸發**：一家基金使用算法大量賣出 E-mini S&P 500 期貨
2. **連鎖反應**：高頻交易算法互相響應
3. **流動性蒸發**：做市商撤單，買盤消失
4. **極端價格**：某些股票跌至 $0.01，某些漲至 $100,000
5. **恢復**：20 分鐘後基本恢復正常

### 關鍵因素

- 算法之間的"共振"
- 流動性提供者同時退出
- 缺乏有效的熔斷機制

### 教訓

| 問題 | 教訓 |
|-----|------|
| 算法交互 | 多個算法可能產生意外共振 |
| 流動性假設 | 危機時流動性會瞬間消失 |
| 極端價格 | 必須設置合理的價格限制 |
| 市場結構 | 高頻交易改變了市場動態 |

### 量化啓示

```
你不是唯一的算法交易者，市場是所有算法的博弈結果
```

## 四、Quant Quake (2007)

### 事件概述

**2007年8月**，多個量化基金在同一週內遭受鉅額虧損。

- **受影響基金**：AQR, Renaissance, Goldman Sachs 等
- **虧損規模**：數十億美元
- **持續時間**：約一週

### 崩潰過程

1. **觸發**：某大型基金開始去槓桿
2. **策略趨同**：多個基金持有相似頭寸
3. **踩踏**：所有人同時賣出相同股票
4. **自我實現**：拋售導致更多虧損，觸發更多拋售

### 根本原因

- **策略擁擠**：太多基金使用相似的因子模型
- **同時去槓桿**：一個基金的拋售影響其他基金
- **相關性上升**：本應分散的策略變得高度相關

### 教訓

| 問題 | 教訓 |
|-----|------|
| 策略擁擠 | 熱門策略的 Alpha 會衰減 |
| 相關性假設 | 危機時策略相關性飆升 |
| 去槓桿風險 | 槓桿策略的退出成本很高 |
| 透明度 | 不知道其他人在做什麼是危險的 |

### 量化啓示

```
如果你的策略太成功，可能有很多人在用同樣的策略
```

## 五、Archegos Capital 爆倉 (2021)

### 事件概述

**Archegos Capital** 是 Bill Hwang 的家族辦公室。

- **日期**：2021年3月
- **虧損**：約 200 億美元
- **銀行損失**：Credit Suisse 55 億，Nomura 30 億

### 崩潰過程

1. **集中持倉**：通過 Total Return Swaps 持有大量科技股
2. **槓桿**：實際槓桿約 5-8 倍
3. **觸發**：ViacomCBS 宣佈增發，股價下跌
4. **追加保證金**：無法滿足 margin call
5. **強制平倉**：銀行大規模拋售股票

### 關鍵問題

- 通過 Swaps 隱藏真實持倉
- 多家銀行不知道對方的敞口
- 單一股票過度集中

### 教訓

| 問題 | 教訓 |
|-----|------|
| 集中風險 | 單一標的持倉過大 |
| 槓桿透明度 | 衍生品可以隱藏真實槓桿 |
| 對手方風險 | 銀行的風控也可能失敗 |
| 信息不對稱 | 沒人知道全貌 |

## 六、WTI原油期貨負價格 (2020年4月)

### 事件概述

**2020年4月20日**，WTI原油5月期貨合約歷史上首次跌至**負價格**。

- **最低價格**：-37.63美元/桶
- **原因**：新冠疫情導致需求崩潰 + 存儲容量危機
- **受害者**：USO ETF投資者、散戶交易者、部分商品基金

### 崩潰過程

1. **新冠封鎖**：全球石油需求暴跌超過30%
2. **存儲爆滿**：俄克拉荷馬州庫欣的存儲容量接近極限
3. **合約到期**：5月合約臨近交割日
4. **恐慌拋售**：交易者倒貼錢甩賣無法實物交割的合約
5. **ETF結構問題**：USO被迫在最差時機展期合約

### 關鍵因素

- 期貨合約的實物交割機制
- 存儲限制導致的負基差
- ETF結構與標的物動態的錯配
- 散戶不理解期貨機制

### 教訓

| 問題 | 教訓 |
|-----|------|
| 合約機制 | 理解交割和展期機制 |
| 實物約束 | 與實物掛鈎的金融工具有現實世界的限制 |
| ETF結構 | ETF不一定完美跟蹤標的 |
| 極端情景 | "價格不可能為負"是危險的假設 |

### 量化啓示

```
永遠不要假設價格有下限，
當存儲滿了，賣家會付錢讓你拿走貨物。
```

## 七、GameStop 逼空事件 (2021年1月)

### 事件概述

**GameStop (GME)** 股票經歷了由 Reddit 散戶論壇 r/WallStreetBets 驅動的歷史性逼空行情。

- **價格變動**：從約20美元漲至盤中最高483美元（2021年1月28日）
- **持續時間**：約兩週的極端波動
- **Melvin Capital 虧損**：約68億美元（資產的53%）
- **總做空方虧損**：估計超過120億美元

### 崩潰過程

1. **高做空比例**：GME做空比例超過流通股的140%
2. **Reddit協作**：r/WallStreetBets社區發現逼空機會
3. **伽馬擠壓**：大量買入看漲期權迫使做市商買入股票對沖
4. **逼空形成**：空頭被迫平倉，推高股價
5. **交易限制**：Robinhood等券商限制買入，引發爭議
6. **後續影響**：國會聽證會、監管審查

### 關鍵因素

- 史無前例的散戶通過社交媒體協作
- 做空比例超過流通股100%
- 期權市場的伽馬動態
- 清算所保證金要求
- 訂單流支付(PFOF)模式受審視

### 教訓

| 問題 | 教訓 |
|-----|------|
| 擁擠的空頭 | >100%的做空比例產生無限逼空風險 |
| 社交媒體 | 散戶協作可以撬動市場 |
| 期權動態 | 伽馬敞口可以指數級放大波動 |
| 券商風險 | 清算要求可能強制暫停交易 |
| 不對稱風險 | 做空有無限虧損潛力 |

### 量化啓示

```
當所有人都在交易的同一邊，
退出的門會變得非常窄。
```

## 八、中國量化地震 (2024年2月)

### 事件概述

**2024年2月5日至8日**，春節前最後四個交易日，中國量化圈經歷史無前例的"量化地震"。

- **受影響機構**：靈均、九坤、幻方、卓識等頭部私募
- **回撤幅度**：中性產品普遍單週跌幅超過 10%
- **持續時間**：4 個交易日（主要衝擊），後續餘波持續數週
- **行業影響**：百億量化私募從 32 家降至 30 家

### 崩潰過程

1. **2024年1月**：雪球結構產品大量敲入，轉換為股票敞口
2. **微盤股擁擠**：量化策略過度集中在小微盤股，追求超額收益
3. **2月5日觸發**：中央匯金大量買入大盤 ETF "救市"
4. **多空雙殺**：大盤上漲導致期貨空頭虧損，小盤下跌導致多頭虧損
5. **DMA 爆倉**：槓桿高達 3 倍的 DMA 產品被迫平倉
6. **踩踏形成**：拋售引發更多拋售，微盤股流動性蒸發
7. **2月8日緩解**：匯金開始買入中證 2000 ETF，危機緩解

### 靈均事件（標誌性案例）

**2月19日**（春節後首個交易日）：
- **開盤1分鐘**：靈均旗下賬戶賣出 25.67 億元股票
- **市場影響**：上證指數、深證成指短時快速下挫
- **處罰**：滬深交易所暫停其交易 3 天，並公開譴責

```
靈均投資聲明：
"2月19日全天整體淨買入 1.87 億元，
但開盤一分鐘內買賣交易量較大，
對於由此造成的負面影響，公司誠懇致歉。"
```

### 虧損數據

| 策略類型 | 平均回撤（截至2月8日） | 最大回撤案例 |
|---------|---------------------|-------------|
| 中證500指增 | -15.52% | 部分產品 > -20% |
| 中證1000指增 | -20.43% | 部分產品 > -30% |
| 市場中性 | -10% 至 -15% | 頭部私募普遍 |
| DMA（槓桿中性） | -20% 至 -40% | 部分產品近乎清盤 |

### 根本原因

- **微盤股過度擁擠**：量化資金集中於流動性差的小微盤
- **風格漂移**：名義上是500指增，實際配置大量2000成分股甚至更小市值
- **槓桿疊加**：DMA 產品槓桿高達 300%
- **雪球敲入共振**：結構性產品集中在相似價位敲入
- **政策干預錯配**：救市資金買大盤，加劇小盤抽血

### 教訓

| 問題 | 教訓 |
|-----|------|
| 微盤擁擠 | 流動性差的股票不能重倉 |
| 風格漂移 | 策略必須與產品説明一致 |
| 槓桿風控 | 極端行情下槓桿是致命的 |
| 政策風險 | "救市"也可能殺死你 |
| 流動性幻覺 | 正常時能賣 ≠ 危機時能賣 |

### 量化啓示

```
當所有量化都在同一個池塘裏捕魚，
池塘乾涸時，沒有人能逃出來。
```

## 九、Renaissance 關稅衝擊 (2025年4月)

### 事件概述

**2025年4月2日**，特朗普宣佈"解放日"關稅政策，全球市場劇烈波動，Renaissance Technologies 旗艦基金遭受重創。

- **觸發事件**：美國宣佈自1930年代以來最激進的關稅政策
- **主要受影響基金**：Renaissance Institutional Equities Fund (RIEF)
- **單月虧損**：約 8%，估計約 16 億美元
- **管理規模**：約 200 億美元

### 崩潰過程

1. **4月2日**：特朗普宣佈全面關稅，市場劇烈重新定價
2. **政策反覆**：關稅政策數日內多次修改，市場劇烈波動
3. **模型失效**：歷史數據無法預測政策驅動的極端行情
4. **RIEF 暴露**：相比毫秒級交易的 Medallion，RIEF 交易頻率較低，無法快速調倉
5. **持續震盪**：後續月份繼續承壓

### 虧損數據

| 基金 | 4月回撤 | 年初至今（截至4月底） | 2024年收益 |
|-----|--------|---------------------|-----------|
| RIEF | -8% | +4.4% | +22.7% |
| RIDA | -2.4% | +11.5% | +15.6% |
| Medallion（內部） | 影響較小 | 仍然強勁 | +30% |

### 關鍵分析

**為什麼 RIEF 特別脆弱？**

```
Medallion vs RIEF 對比：

Medallion（內部基金）：
- 交易頻率：毫秒級
- 持倉週期：極短
- 可以快速適應市場變化

RIEF（外部投資者基金）：
- 交易頻率：較低
- 持倉週期：較長
- 政策突變時調倉速度跟不上
```

### 教訓

| 問題 | 教訓 |
|-----|------|
| 政策黑天鵝 | 政治事件無法用歷史數據預測 |
| 交易頻率 | 低頻策略在高波動環境下更脆弱 |
| 模型侷限 | 再強的量化模型也有盲區 |
| 風險分散 | 不同頻率策略應該分開管理 |

### 量化啓示

```
量化模型擅長髮現市場規律，
但政治家的嘴，不在模型的訓練集裏。
```

## 十、共同教訓總結

### 10.1 風控原則

1. **槓桿限制**：設定最大槓桿上限
2. **分散化**：單一標的、策略、市場不能過度集中
3. **流動性緩衝**：保持足夠的現金或流動性資產
4. **熔斷機制**：自動停止交易的觸發條件

### 10.2 技術原則

1. **代碼審查**：所有上線代碼必須經過審查
2. **灰度部署**：逐步部署，不要一次全量
3. **實時監控**：異常必須立即告警
4. **回滾能力**：必須能在分鐘內回滾

### 10.3 認知原則

1. **尾部風險**：小概率事件總會發生
2. **模型侷限**：歷史數據不能預測未來
3. **策略擁擠**：成功策略會吸引模仿者
4. **相關性陷阱**：危機時所有相關性趨向於 1

## 十一、風控檢查清單

在上線任何策略前，問自己：

- [ ] 最大虧損是多少？能承受嗎？
- [ ] 如果市場流動性消失，能退出嗎？
- [ ] 如果代碼出錯，能在多久內發現並停止？
- [ ] 如果其他人在用同樣策略，會發生什麼？
- [ ] 如果發生 2008 年級別的危機，策略會怎樣？

---

> **核心原則**：在量化交易中，活得久比賺得多更重要。控制好風險，你才有機會等到下一次盈利。
