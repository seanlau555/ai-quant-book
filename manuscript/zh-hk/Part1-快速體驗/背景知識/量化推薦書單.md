# 背景：推薦閱讀書單

> 系統地學習量化交易，需要橫跨多個領域：金融、統計、machine learning 和編程。本書單按學習次序與難度編排。

---

## 關於本書

**《AI 量化交易：從 0 到 1》** 正是為降低這道學習門檻而寫。

我從下列經典著作中提煉出最核心、最實用的內容，結合 multi-agent 架構的現代視角，以故事帶動、代碼為輔的方式重新編排。無論你想快速入門，還是想系統地了解量化交易的全貌，本書都可以作為你的第一站——讀完之後，你可以按自己的興趣，再深入閱讀下面的專門著作。

當然，在步伐急速的今天，個人的時間和精力未必容許閱讀所有這些資料。我的書從本質和重點入手，由 AI 和 agent 的新技術框架驅動，本質上是簡化了部分可以被革新的傳統舊概念和步驟。當然，這是主觀的看法。

## 7. 風險管理與資金管理

### 7.1 資金管理（最優先）

> **Van K. Tharp 的觀點**：在真實交易中，資金管理至少佔 50%。無論策略多好，倉位管理不當都會令帳戶爆倉。

**"Trade Your Way to Financial Freedom" - Van K. Tharp**
- 難度：中級
- 內容：完整的交易系統設計
- 重點章節：
  - Position Sizing：決定每筆交易投入多少
  - Expectancy：勝率 × 風險回報比的真正含義
  - R-Multiple：以風險單位衡量回報
  - 系統開發流程
- 特點：**極為實用，能改變交易思維**
- 必讀指數：⭐⭐⭐⭐⭐
- 適合：所有交易者（比策略書籍更重要）

**"The Definitive Guide to Position Sizing" - Van K. Tharp**
- 難度：中級至進階
- 內容：倉位管理深度指南
- 核心：
  - Fixed Fractional 方法
  - Fixed Ratio 方法
  - Kelly 公式及其局限
  - Risk Parity
- 特點：倉位管理專著，細節豐富
- 適合：已讀完上一本的進階讀者

**Van K. Tharp 的核心公式**：

```
Expectancy = (Win Rate × Average Win) - (Loss Rate × Average Loss)

R-Multiple = Actual Profit/Loss / Initial Risk (stop-loss distance)

Position Size = Account Risk Percentage / Single Trade Risk
             = (Total Capital × 2%) / (Entry Price - Stop Loss Price)
```

**為何資金管理最重要**：
- 策略勝率 60%，但倉位管理不佳 → 虧損
- 策略勝率 40%，但倉位管理得宜 → 獲利
- 關鍵不在於「對了多少次」，而在於「對的時候賺多少，錯的時候虧多少」

## 8. 建議閱讀次序

### 初學者路徑（6-12 個月）

```
Phase 1 (Fundamentals)
├── Random Walk Down Wall Street
├── Quantitative Trading (Chan)
└── Python for Finance

Phase 2 (Capital Management - Most Important!)
├── Trade Your Way to Financial Freedom ⭐ (Van K. Tharp)
└── Trading in the Zone (Mark Douglas)

Phase 3 (Strategy)
├── Following the Trend
├── Stocks on the Move
└── Algorithmic Trading (Chan)

Phase 4 (Advanced)
├── Advances in Financial Machine Learning ⭐
└── Analysis of Financial Time Series
```

> **重要**：很多人跳過第二階段，直接去研究策略——這是最常見的錯誤。資金管理決定生存；策略只是錦上添花。

### Machine Learning 路徑（3-6 個月）

```
├── Elements of Statistical Learning
├── Hands-On Machine Learning
├── Advances in Financial Machine Learning ⭐
└── Reinforcement Learning (Sutton)
```

### 高頻／執行路徑（6-12 個月）

```
├── Trading and Exchanges
├── Market Microstructure Theory
└── Algorithmic and High-Frequency Trading
```

## 10. 閱讀建議

1. **不要跳過基礎**：先讀入門書，再讀進階書
2. **邊讀邊實踐**：每讀完一章，就用代碼實現一次
3. **重讀經典**：López de Prado 的著作值得反覆閱讀
4. **保持懷疑**：任何策略都可能過時
5. **理論 + 實踐**：理論書與實踐書交替閱讀

---

> **核心原則**：書本只是起點，真正的學習來自實踐。讀完一本書後，你能否用代碼實現其內容，才是檢驗學習成效的真正標準。
