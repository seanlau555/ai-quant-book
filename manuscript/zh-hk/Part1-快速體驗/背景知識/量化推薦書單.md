# 背景知識：量化推薦書單

> 系統學習量化交易需要跨越多個領域：金融、統計、機器學習、編程。本書單按學習順序和難度排列。

---

## 關於本書

**《AI量化交易從0到1》** 正是為了降低這個學習門檻而寫。

我從下述經典著作中提煉了最核心、最實用的內容，結合多智能體架構這一現代視角，用故事驅動、代碼可選的方式重新組織。無論你是想快速入門，還是想系統瞭解量化交易的全貌，本書都可以作為你的第一站——讀完後再根據興趣深入以下專著。

當然在現代快餐社會，個人的精力與時間都不一定能夠將大量資料全部讀完學完。我的這本書更是從精髓和核心要點切入，從AI與智能體（當前時間點2026年1月）的新技術框架下驅動實踐，本質上也直接降維了一些傳統的舊理念與可被革命的步驟。當然這裏仁者見仁了。

## 七、風險管理與資金管理

### 7.1 資金管理（重中之重）

> **Van K. Tharp 觀點**：資金管理的重要性在實戰中佔比至少 50%。策略再好，倉位管理不當也會爆倉。

**《Trade Your Way to Financial Freedom》- Van K. Tharp**
- 難度：中級
- 內容：完整的交易系統設計
- 核心章節：
  - 頭寸管理（Position Sizing）：決定每筆交易投入多少
  - 期望值（Expectancy）：勝率 × 盈虧比的真正含義
  - R 倍數（R-Multiple）：用風險單位衡量收益
  - 系統開發流程
- 特點：**實戰性極強，改變交易思維**
- 必讀指數：⭐⭐⭐⭐⭐
- 適合：所有交易者（比策略書更重要）

**《The Definitive Guide to Position Sizing》- Van K. Tharp**
- 難度：中-高級
- 內容：頭寸管理的深度指南
- 核心：
  - 固定比例法（Fixed Fractional）
  - 固定比率法（Fixed Ratio）
  - 凱利公式及其侷限
  - 風險平價（Risk Parity）
- 特點：資金管理專著，細節豐富
- 適合：已讀完上一本的進階讀者

**Van K. Tharp 核心公式**：

```
期望值 = (勝率 × 平均盈利) - (敗率 × 平均虧損)

R 倍數 = 實際盈虧 / 初始風險（止損距離）

倉位大小 = 賬戶風險比例 / 單筆交易風險
         = (總資金 × 2%) / (入場價 - 止損價)
```

**為什麼資金管理最重要**：
- 策略勝率 60%，但倉位管理不當 → 虧損
- 策略勝率 40%，但倉位管理得當 → 盈利
- 關鍵不是"對多少次"，而是"對的時候賺多少，錯的時候虧多少"

## 八、推薦閲讀順序

### 初學者路徑（6-12個月）

```
第1階段（基礎）
├── Random Walk Down Wall Street
├── Quantitative Trading (Chan)
└── Python for Finance

第2階段（資金管理 - 最重要！）
├── Trade Your Way to Financial Freedom ⭐ (Van K. Tharp)
└── Trading in the Zone (Mark Douglas)

第3階段（策略）
├── Following the Trend
├── Stocks on the Move
└── Algorithmic Trading (Chan)

第4階段（進階）
├── Advances in Financial Machine Learning ⭐
└── Analysis of Financial Time Series
```

> **重要**：很多人跳過第2階段直接研究策略，這是最常見的錯誤。資金管理決定生死，策略只是錦上添花。

### 機器學習路徑（3-6個月）

```
├── Elements of Statistical Learning
├── Hands-On Machine Learning
├── Advances in Financial Machine Learning ⭐
└── Reinforcement Learning (Sutton)
```

### 高頻/執行路徑（6-12個月）

```
├── Trading and Exchanges
├── Market Microstructure Theory
└── Algorithmic and High-Frequency Trading
```

## 十、閲讀建議

1. **不要跳過基礎**：先讀入門書，再讀高級書
2. **邊讀邊練**：每讀完一章，寫代碼實現
3. **重讀經典**：López de Prado 的書值得讀多遍
4. **保持懷疑**：任何策略都可能過時
5. **理論+實踐**：理論書和實操書交替閲讀

---

> **核心原則**：書只是起點，真正的學習來自實踐。讀完一本書後，能否用代碼實現書中的內容，才是檢驗學習效果的標準。
