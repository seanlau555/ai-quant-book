## 學完本階段後

你將能夠：
- ✅ 理解股票、期貨、加密貨幣等不同市場的特點
- ✅ 用數學語言描述收益和風險
- ✅ 識別技術指標的真實價值和侷限
- ✅ 搭建數據管道，處理 API 限流、數據缺失等問題
- ✅ 避免回測中的常見陷阱（過擬合、未來函數等）
- ✅ 理解 Beta 和 Alpha 的區別，知道收益從哪裏來
- ✅ 計算對沖比例，理解為什麼市場中性難做
