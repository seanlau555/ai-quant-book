# 第04課：技術指標的真實角色

> **核心洞察**：Indicator 不是「買入/賣出訊號」，而是 feature engineering。

---

## 「黃金交叉必升」的幻覺

小李是股市新手。他在網上學到一條「必勝」規則：**MACD 黃金交叉買入，死亡交叉賣出**。

他興奮地寫了程式，用 10 年數據做 backtest。結果：勝率 52%，年化 return -8%。

「怎麼可能？黃金交叉明明是看漲訊號！」

他又試了 RSI 超賣買入、Bollinger Bands 下軌買入、均線多頭排列買入……每一個「經典訊號」單獨使用時，勝率都徘徊在 50% 左右，扣除手續費後全部蝕錢。

**問題出在哪裏？**

小李犯了一個常見的錯誤：**把技術指標當作買賣訊號**。

真相是：
1. **Indicator 是滯後的**：到 MACD 黃金交叉時，價格已經升了
2. **Indicator 是簡化的**：單一數字無法捕捉複雜的市場狀態
3. **Indicator 會被利用**：當所有人都看同一個訊號，這個訊號就會失效

**那麼技術指標到底有什麼用？**

答案是：**Feature engineering**。Indicator 不是用來直接交易的，而是用來描述市場狀態的。當你把幾十個 indicator（MACD、RSI、Bollinger Bands 等）合併起來，作為 machine learning 模型的輸入 feature，它們才能真正發揮價值。

本課目標：幫助你理解技術指標的本質，並學會正確使用。

---

## 4.1 Indicator 的本質

### Indicator = 數學變換

所有技術指標，本質上都是對價格和成交量的數學變換：

| 原始數據 | 變換方法 | 得出的 Indicator |
|----------|----------------------|---------------------|
| 收市價序列 | Moving average | MA (Moving Average) |
| 收市價序列 | 指數加權平均 | EMA (Exponential Moving Average) |
| 價格變動序列 | 相對強弱計算 | RSI |
| 價格序列 | Mean +/- standard deviation | Bollinger Bands |
| 最高、最低、收市價 | 多重計算 | MACD |

**核心洞察**：Indicator 並不創造新資訊，只是以不同方式呈現既有資訊。

### 滯後是與生俱來的屬性

任何由歷史數據計算出來的 indicator，天生就是**滯後**的：

```
Price has already changed
        |
    Calculate indicator
        |
   Indicator generates signal
        |
    You take action
        |
  Price may have already reversed
```

| Indicator | 典型參數 | 滯後幅度 |
|-----------|-------------------|------------|
| MA5 | 5 日平均 | 約 2-3 日 |
| MA20 | 20 日平均 | 約 10 日 |
| MACD | 12, 26, 9 | 約 5-10 日 |
| RSI(14) | 14 日 | 約 7 日 |

**重點**：不要期望 indicator 能「預測」未來，它們只能描述「現在」和「過去」。

### 資訊壓縮與損失

把幾百日的價格數據壓縮成單一數字（例如 RSI=65），必然損失大量資訊：

- 價格的分佈形態？損失了
- 成交量的變化模式？損失了
- 日內 volatility 特徵？損失了

**這就是為何單一 indicator 無法有效指導交易**：資訊太少。

## 4.2 趨勢 Indicator

### MA / EMA：平滑與滯後的取捨

**Moving Average (MA)**：過去 N 日收市價的簡單平均。

```
MA(5) = (P1 + P2 + P3 + P4 + P5) / 5
```

**Exponential Moving Average (EMA)**：給予近期價格較高權重。

```
EMA = Today's price x alpha + Yesterday's EMA x (1-alpha)
where alpha = 2 / (N+1)
```

| 比較 | MA (Simple Moving Average) | EMA (Exponential Moving Average) |
|------------|---------------------------|----------------------------------|
| 權重分佈 | 平均 | 近期數據較高 |
| 對新數據的反應 | 慢 | 快 |
| 平滑度 | 較平滑 | 較敏感 |
| 使用情境 | 長期趨勢 | 短期趨勢 |

**核心取捨**：參數越小 -> 越敏感 -> noise 越多；參數越大 -> 越穩定 -> 滯後越多。

### MACD：趨勢與 Momentum

MACD 是最常用的趨勢 indicator 之一，由三部分組成：

```
DIFF (Fast line) = EMA12 - EMA26
DEA (Signal line) = EMA9(DIFF)
Histogram = 2 x (DIFF - DEA)
```

> **平台備註**：部分交易平台（特別是亞洲市場的平台，如 TradingView 中國版、同花順）會將 histogram 乘以 2，而西方平台通常不會。引用 MACD 數值時，務必確認你的平台使用的公式。

**直觀理解**：
- DIFF：短期與長期趨勢之間的差距
- DEA：DIFF 的平滑版本
- Histogram：趨勢加速/減速的程度

| MACD 狀態 | 意義 | 市場解讀 |
|------------|---------|----------------------|
| DIFF > 0，Histogram 擴張 | 升勢加速 | 多頭強勢 |
| DIFF > 0，Histogram 收縮 | 升勢減速 | 可能見頂 |
| DIFF < 0，Histogram 收縮 | 跌勢減速 | 可能見底 |
| DIFF < 0，Histogram 擴張 | 跌勢加速 | 空頭強勢 |

### Divergence 分析

**Divergence（背馳）** 是技術分析中最重要的概念之一：

| Divergence 類型 | 價格表現 | MACD 表現 | 意義 |
|----------------|----------------|---------------|---------|
| **Bearish Divergence** | 創新高 | 未創新高 | 上升動能耗盡，可能下跌 |
| **Bullish Divergence** | 創新低 | 未創新低 | 下跌動能耗盡，可能上升 |

```
Bearish divergence example:
Price:  100 -> 110 -> 120 -> 125 -> 130 (new high)
MACD:    10 ->  15 ->  18 ->  16 ->  14 (no new high)
                              ^
                         Momentum exhaustion signal
```

**重要警告**：
- Divergence 只是「可能」的訊號，不是「確定」的訊號
- 單憑 divergence 交易，勝率通常只有 55-60%
- 需要其他 indicator 和市場結構來確認

## 4.3 Oscillator Indicator

### RSI：相對強弱

RSI 衡量近期升跌的相對強度：

```
RS = Average gain / Average loss
RSI = 100 - 100/(1+RS)
```

RSI 的範圍為 0-100：

| RSI 範圍 | 傳統解讀 | 現實 |
|-----------|---------------------------|---------|
| > 70 | 超買，應該賣出 | 強勢市場可以長期維持在 80 以上 |
| 30-70 | 正常範圍 | 大部分時間都在此區間 |
| < 30 | 超賣，應該買入 | 弱勢市場可以長期維持在 20 以下 |

**RSI 的真實用法**：
- 不要單靠 70/30 作為買賣訊號
- RSI 的趨勢更重要：RSI 由 30 向上升，與 RSI 在 60-70 之間擺動，意義不同
- RSI divergence 同樣有效：價格創新高但 RSI 沒有 = bearish divergence

### Bollinger Bands

Bollinger Bands 由三條線組成：

```
Middle band = MA20 (20-day moving average)
Upper band = MA20 + 2 sigma (mean + 2 standard deviations)
Lower band = MA20 - 2 sigma (mean - 2 standard deviations)
```

**統計意義**：在 normal distribution 假設下，價格有 95% 機率處於上下軌之間。

| Bollinger 訊號 | 傳統解讀 | 適用情境 |
|------------------|---------------------------|---------------------|
| 觸及上軌 | 超買，可能回調 | 橫行市 |
| 觸及下軌 | 超賣，可能反彈 | 橫行市 |
| 突破上軌 | 趨勢開始 | 趨勢市 |
| 通道收窄 | Volatility 下降，即將 breakout | 所有市場 |

**關鍵洞察**：Bollinger Bands 在橫行市是「reversion」訊號，在趨勢市則是「breakout」訊號，你需要先識別市場狀態。

## 4.4 Volatility Indicator

### Historical Volatility

Historical Volatility = 過去 N 日 return 的 standard deviation x sqrt(252)（年化）

```
Example calculation:
Daily return standard deviation = 2%
Annualized volatility = 2% x sqrt(252) ~ 31.7%
```

| 年化 Volatility | 典型 Asset | 風險水平 |
|-----------------------|----------------|------------|
| 10-15% | 債券、大型藍籌股 | 低 |
| 20-30% | 一般股票 | 中 |
| 40-60% | 小型股、加密貨幣 | 高 |
| 80%+ | Altcoin、臨近到期的 option | 極高 |

### ATR (Average True Range)

ATR 衡量「真實波動幅度」，並計及 gap：

```
True Range = max(
    Today's High - Today's Low,
    |Today's High - Yesterday's Close|,
    |Today's Low - Yesterday's Close|
)
ATR = N-day average of True Range
```

**ATR 的實際用途**：
- 設定 stop-loss：止損距離 = 入場價 +/- 2 x ATR
- Position sizing：volatility 高時減倉，低時可加倉
- Breakout 確認：突破幅度 > 1 x ATR 更可能是真突破

## 4.5 策略評估指標

這些指標用來評估策略表現，而不是交易訊號：

### Sharpe Ratio

```
Sharpe Ratio = (Rp - Rf) / sigma_p

Rp = Portfolio return
Rf = Risk-free rate (e.g., Treasury yield)
sigma_p = Standard deviation of returns
```

**直觀理解**：每承擔一單位風險，能獲得多少超額 return。

| Sharpe Ratio | 評價 |
|--------------|------------|
| < 0 | 蝕錢，比銀行存款還差 |
| 0-1 | 一般，未必值得承擔風險 |
| 1-2 | 良好 |
| 2-3 | 優秀 |
| > 3 | 頂級（或數據有問題） |

### 其他風險指標

| 指標 | 公式 | 意義 |
|--------|---------|---------|
| **Sortino Ratio** | (Rp - Rf) / sigma_downside | 只懲罰下行 volatility，聚焦虧損風險 |
| **Maximum Drawdown** | 由高峰至低谷的最大跌幅 | 最壞情況下的虧損 |
| **Calmar Ratio** | 年化 return / Max drawdown | Return 與 drawdown 的平衡 |
| **VaR (95%)** | 95% 信心水平下的最大虧損 | 正常情況下的風險界限 |

**例子**：
- 年化 return 20%、max drawdown 40% 的策略 -> Calmar = 0.5（一般）
- 年化 return 15%、max drawdown 10% 的策略 -> Calmar = 1.5（優秀）

## 4.6 Indicator 組合：由訊號到 Feature

### 為何單一 Indicator 行不通

實證研究顯示，單一技術指標的預測能力非常有限：

| 策略 | 勝率 | 年化 Return（扣除手續費後） |
|----------|----------|-------------------------------|
| MACD 黃金/死亡交叉 | 51% | -5% 至 +3% |
| RSI 超買/超賣 | 52% | -3% 至 +5% |
| Bollinger Band Breakout | 50% | -8% 至 +2% |
| 雙均線交叉 | 53% | -2% 至 +8% |

> **注意**：這些數字只是示意/參考值。實際表現會因市場、時間框架、參數設定及成本假設（佣金、slippage、bid-ask spread）而有很大差異。務必用自己的 backtest 驗證。

**原因**：
1. 所有市場參與者都看同一個訊號 -> 訊號早已被 price in
2. 不同市場狀態需要不同解讀 -> 單一規則無法適應
3. Indicator 的資訊不完整 -> 需要多維度驗證

### 將 Indicator 正確用作 Feature

```
Traditional usage (wrong):
RSI < 30 -> Buy

Correct usage (feature engineering):
Feature vector = [
    RSI,
    RSI rate of change,
    MACD_DIFF,
    MACD_Histogram rate of change,
    Bollinger Band position (price's relative position within bands),
    ATR (volatility),
    Volume rate of change,
    ...more features
]
-> Input to ML model -> Output: Buy/Sell/Hold + Confidence
```

**Multi-Agent 視角**：
- Trend Agent：專注 MACD、moving average、ATR
- Mean Reversion Agent：專注 RSI、Bollinger Bands、偏離度
- Regime Agent：專注 volatility 變化、correlation 變化
- Risk Agent：專注 VaR、max drawdown、Sharpe 變化

## 代碼實現（選讀）

如果你想動手練習，以下是計算 indicator 的示例代碼：

```python
import pandas as pd
import numpy as np

def calculate_indicators(df):
    """
    Calculate common technical indicators
    df needs columns: open, high, low, close, volume
    """
    # EMA
    df['EMA12'] = df['close'].ewm(span=12).mean()
    df['EMA26'] = df['close'].ewm(span=26).mean()

    # MACD
    df['MACD_DIFF'] = df['EMA12'] - df['EMA26']
    df['MACD_DEA'] = df['MACD_DIFF'].ewm(span=9).mean()
    df['MACD_Histogram'] = 2 * (df['MACD_DIFF'] - df['MACD_DEA'])

    # RSI
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0).rolling(14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
    # Avoid division by zero: when loss=0 (continuous up moves), RSI=100
    rs = gain / loss.replace(0, np.nan)
    df['RSI'] = (100 - 100 / (1 + rs)).fillna(100)

    # Bollinger Bands
    df['BB_Middle'] = df['close'].rolling(20).mean()
    df['BB_Std'] = df['close'].rolling(20).std()
    df['BB_Upper'] = df['BB_Middle'] + 2 * df['BB_Std']
    df['BB_Lower'] = df['BB_Middle'] - 2 * df['BB_Std']
    df['BB_Position'] = (df['close'] - df['BB_Lower']) / (df['BB_Upper'] - df['BB_Lower'])

    # ATR
    high_low = df['high'] - df['low']
    high_close = (df['high'] - df['close'].shift()).abs()
    low_close = (df['low'] - df['close'].shift()).abs()
    tr = pd.concat([high_low, high_close, low_close], axis=1).max(axis=1)
    df['ATR'] = tr.rolling(14).mean()

    return df

def calculate_sharpe_ratio(returns, risk_free_rate=0.04, periods_per_year=252):
    """Calculate Sharpe Ratio"""
    excess_returns = returns - risk_free_rate / periods_per_year
    return np.sqrt(periods_per_year) * excess_returns.mean() / returns.std()
```
