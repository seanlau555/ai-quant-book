# 第 04 課：技術指標的真實角色

> **核心觀點**：指標不是"買賣信號"，而是特徵工程。

---

## "金叉必漲"的幻滅

小李是一個股票新手。他在網上學到了一個"必勝法則"：**MACD 金叉買入，死叉賣出**。

他興奮地寫了一個程式，回測過去 10 年的數據。結果：勝率 52%，年化收益 -8%。

"怎麼可能？金叉明明是上漲信號啊！"

他又試了 RSI 超賣買入、布林帶下軌買入、均線多頭排列買入……每一個"經典信號"，單獨使用時勝率都在 50% 附近徘徊，扣掉手續費後全部虧損。

**問題出在哪裏？**

小李犯了一個常見錯誤：**把技術指標當成買賣信號**。

真相是：
1. **指標是滯後的**：MACD 金叉時，價格已經漲了一段
2. **指標是簡化的**：一個數字無法概括複雜的市場狀態
3. **指標是被利用的**：當所有人都在看同一個信號，信號就失效了

**那技術指標到底有什麼用？**

答案是：**特徵工程**。指標不是用來直接交易的，而是用來描述市場狀態的。當你把 MACD、RSI、布林帶等幾十個指標組合在一起，作為機器學習模型的輸入特徵，它們才能發揮真正的價值。

這一課的目標：讓你理解技術指標的本質，學會正確使用它們。

---

## 4.1 指標的本質

### 指標 = 數學變換

所有技術指標，本質上都是對價格和成交量的數學變換：

| 原始數據 | 變換方式 | 得到的指標 |
|---------|---------|-----------|
| 收盤價序列 | 滑動平均 | MA（移動平均線）|
| 收盤價序列 | 指數加權平均 | EMA（指數移動平均）|
| 漲跌幅序列 | 相對強度計算 | RSI |
| 價格序列 | 均值 ± 標準差 | 布林帶 |
| 最高價、最低價、收盤價 | 多重計算 | MACD |

**核心洞察**：指標不會創造新信息，只是換一種方式呈現已有信息。

### 滯後性是固有屬性

任何基於歷史數據計算的指標，都必然是**滯後的**：

```
價格已經發生變化
        ↓
    計算指標
        ↓
   指標發出信號
        ↓
    你採取行動
        ↓
  此時價格可能已經反轉
```

| 指標 | 典型參數 | 滯後程度 |
|-----|---------|---------|
| MA5 | 5 日均線 | 約 2-3 天 |
| MA20 | 20 日均線 | 約 10 天 |
| MACD | 12, 26, 9 | 約 5-10 天 |
| RSI(14) | 14 日 | 約 7 天 |

**啓示**：不要指望指標能"預測"未來，它們只能描述"現在"和"過去"。

### 信息壓縮與損失

把幾百天的價格數據，壓縮成一個數字（比如 RSI=65），必然會損失大量信息：

- 價格的分佈形態？丟失了
- 成交量的變化模式？丟失了
- 盤中的波動特徵？丟失了

**這就是為什麼單一指標無法有效指導交易**——信息太少了。

## 4.2 趨勢類指標

### MA / EMA：平滑與滯後的權衡

**移動平均線 (MA)**：過去 N 天收盤價的簡單平均。

```
MA(5) = (P₁ + P₂ + P₃ + P₄ + P₅) / 5
```

**指數移動平均線 (EMA)**：給近期價格更高的權重。

```
EMA = 今日價格 × α + 昨日EMA × (1-α)
其中 α = 2 / (N+1)
```

| 對比 | MA（簡單移動平均）| EMA（指數移動平均）|
|-----|-----------------|-------------------|
| 權重分佈 | 平均 | 近期更高 |
| 對新數據反應 | 慢 | 快 |
| 平滑程度 | 更平滑 | 更靈敏 |
| 適用場景 | 長期趨勢 | 短期趨勢 |

**核心權衡**：參數越小 → 越靈敏 → 越多噪音；參數越大 → 越穩定 → 越滯後。

### MACD：趨勢與動量

MACD 是最常用的趨勢指標之一，由三部分組成：

```
DIFF (快線) = EMA₁₂ - EMA₂₆
DEA (信號線) = EMA₉(DIFF)
柱狀圖 = 2 × (DIFF - DEA)  ← 中國軟件慣例
```

> **注意**：`2×` 係數是國內軟件（同花順、通達信）的慣例。國際標準（TradingView、MetaTrader）使用 `DIFF - DEA`，無 2× 係數。使用不同平台時請注意差異。

**直觀理解**：
- DIFF：短期趨勢與長期趨勢的差距
- DEA：DIFF 的平滑版本
- 柱狀圖：趨勢加速/減速的程度

| MACD 狀態 | 含義 | 市場解讀 |
|----------|------|---------|
| DIFF > 0, 柱狀圖變大 | 上漲趨勢加速 | 多頭強勢 |
| DIFF > 0, 柱狀圖變小 | 上漲趨勢減速 | 可能見頂 |
| DIFF < 0, 柱狀圖變小 | 下跌趨勢減速 | 可能見底 |
| DIFF < 0, 柱狀圖變大 | 下跌趨勢加速 | 空頭強勢 |

### 背離分析

**背離**是技術分析中最重要的概念之一：

| 背離類型 | 價格表現 | MACD 表現 | 含義 |
|---------|---------|----------|------|
| **頂背離** | 創新高 | 未創新高 | 上漲動能衰竭，可能下跌 |
| **底背離** | 創新低 | 未創新低 | 下跌動能衰竭，可能上漲 |

```
頂背離示意：
價格:  100 → 110 → 120 → 125 → 130（新高）
MACD:   10 →  15 →  18 →  16 →  14（未新高）
                              ↑
                         動能衰竭信號
```

**重要警告**：
- 背離只是"可能"的信號，不是"確定"的信號
- 單獨使用背離交易，勝率通常只有 55-60%
- 需要結合其他指標和市場結構驗證

## 4.3 振盪類指標

### RSI：相對強弱

RSI 衡量近期漲跌的相對強度：

```
RS = 平均上漲幅度 / 平均下跌幅度
RSI = 100 - 100/(1+RS)
```

RSI 的範圍是 0-100：

| RSI 區間 | 傳統解讀 | 實際情況 |
|---------|---------|---------|
| > 70 | 超買，應該賣出 | 強勢市場可能持續 > 80 |
| 30-70 | 正常區間 | 大部分時間在這裏 |
| < 30 | 超賣，應該買入 | 弱勢市場可能持續 < 20 |

**RSI 的真實用法**：
- 不要單獨依賴 70/30 作為買賣信號
- RSI 的趨勢更重要：RSI 從 30 上升 vs RSI 一直在 60-70 震盪
- RSI 背離同樣有效：價格新高但 RSI 未新高 = 頂背離

### 布林帶 (Bollinger Bands)

布林帶由三條線組成：

```
中軌 = MA₂₀（20日移動平均線）
上軌 = MA₂₀ + 2σ（均值 + 2倍標準差）
下軌 = MA₂₀ - 2σ（均值 - 2倍標準差）
```

**統計含義**：在正態分佈假設下，價格有 95% 的概率在上下軌之間。

| 布林帶信號 | 傳統解讀 | 適用場景 |
|-----------|---------|---------|
| 觸及上軌 | 超買，可能回落 | 震盪市 |
| 觸及下軌 | 超賣，可能反彈 | 震盪市 |
| 突破上軌 | 趨勢開始 | 趨勢市 |
| 帶寬收窄 | 波動率降低，即將突破 | 所有市場 |

**關鍵洞察**：布林帶在震盪市是"迴歸"信號，在趨勢市是"突破"信號——你需要先判斷市場狀態。

## 4.4 波動率指標

### 歷史波動率

歷史波動率 = 過去 N 天收益率的標準差 × √252（年化）

```
示例計算：
日收益率標準差 = 2%
年化波動率 = 2% × √252 ≈ 31.7%
```

| 年化波動率 | 典型資產 | 風險等級 |
|-----------|---------|---------|
| 10-15% | 債券、大盤藍籌 | 低 |
| 20-30% | 普通股票 | 中 |
| 40-60% | 小盤股、加密貨幣 | 高 |
| 80%+ | 山寨幣、末日期權 | 極高 |

### ATR（Average True Range）

ATR 衡量"真實波動幅度"，考慮了跳空缺口：

```
True Range = max(
    當日最高 - 當日最低,
    |當日最高 - 昨日收盤|,
    |當日最低 - 昨日收盤|
)
ATR = True Range 的 N 日平均
```

**ATR 的實戰用途**：
- 止損設置：止損距離 = 入場價 ± 2×ATR
- 倉位管理：波動率高時減倉，波動率低時可適當加倉
- 突破確認：突破幅度 > 1×ATR 更可能是真突破

## 4.5 策略評價指標

這些指標用於評估策略表現，而非交易信號：

### Sharpe Ratio（夏普比率）

```
Sharpe Ratio = (Rₚ - Rᶠ) / σₚ

Rₚ = 投資組合收益率
Rᶠ = 無風險利率（如國債收益率）
σₚ = 收益的標準差
```

**直觀理解**：每承擔 1 單位風險，能獲得多少超額收益。

| Sharpe Ratio | 評價 |
|--------------|------|
| < 0 | 虧損，不如存銀行 |
| 0-1 | 一般，可能不值得冒險 |
| 1-2 | 良好 |
| 2-3 | 優秀 |
| > 3 | 頂級（或數據有問題）|

### 其他風險指標

| 指標 | 公式 | 含義 |
|-----|------|------|
| **Sortino Ratio** | (Rₚ - Rᶠ) / σ_下行 | 只懲罰下跌波動，更關注虧損風險 |
| **Maximum Drawdown** | 從峯值到谷底的最大跌幅 | 最壞情況會虧多少 |
| **Calmar Ratio** | 年化收益 / 最大回撤 | 收益與回撤的平衡 |
| **VaR (95%)** | 95% 置信度下的最大損失 | 正常情況下的風險邊界 |

**示例**：
- 策略年化收益 20%，最大回撤 40% → Calmar = 0.5（一般）
- 策略年化收益 15%，最大回撤 10% → Calmar = 1.5（優秀）

## 4.6 指標組合：從信號到特徵

### 為什麼單一指標無效？

實證研究表明，單一技術指標的預測能力非常有限：

| 策略 | 勝率 | 年化收益（扣除手續費後）|
|-----|------|----------------------|
| MACD 金叉/死叉 | 51% | -5% ~ +3% |
| RSI 超買超賣 | 52% | -3% ~ +5% |
| 布林帶突破 | 50% | -8% ~ +2% |
| 雙均線交叉 | 53% | -2% ~ +8% |

> **説明**：以上數據為示意性參考，實際表現因市場、時間段、參數設置和交易成本假設而異。

**原因**：
1. 市場參與者都在看同一個信號 → 信號被提前消化
2. 不同市場狀態需要不同解讀 → 單一規則無法適應
3. 指標信息不完整 → 需要多維度驗證

### 指標作為特徵的正確用法

```
傳統用法（錯誤）：
RSI < 30 → 買入

正確用法（特徵工程）：
特徵向量 = [
    RSI,
    RSI 變化率,
    MACD_DIFF,
    MACD_柱狀圖變化率,
    布林帶位置（價格在帶中的相對位置）,
    ATR（波動率）,
    成交量變化率,
    ...更多特徵
]
→ 輸入機器學習模型 → 輸出：買入/賣出/持有 + 置信度
```

**多智能體視角**：
- Trend Agent：關注 MACD、均線、ATR
- Mean Reversion Agent：關注 RSI、布林帶、偏離度
- Regime Agent：關注波動率變化、相關性變化
- Risk Agent：關注 VaR、最大回撤、Sharpe 變化

## 💻 代碼實現（可選）

如果你想動手實踐，這裏提供計算指標的示例代碼：

```python
import pandas as pd
import numpy as np

def calculate_indicators(df):
    """
    計算常用技術指標
    df 需要包含: open, high, low, close, volume 列
    """
    # EMA
    df['EMA12'] = df['close'].ewm(span=12).mean()
    df['EMA26'] = df['close'].ewm(span=26).mean()

    # MACD
    df['MACD_DIFF'] = df['EMA12'] - df['EMA26']
    df['MACD_DEA'] = df['MACD_DIFF'].ewm(span=9).mean()
    df['MACD_Histogram'] = 2 * (df['MACD_DIFF'] - df['MACD_DEA'])

    # RSI（處理除零情況）
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0).rolling(14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(14).mean()
    rs = gain / loss.replace(0, np.nan)  # 避免除零
    df['RSI'] = 100 - 100 / (1 + rs)
    df['RSI'] = df['RSI'].fillna(100)  # 連續上漲時 RSI=100

    # Bollinger Bands
    df['BB_Middle'] = df['close'].rolling(20).mean()
    df['BB_Std'] = df['close'].rolling(20).std()
    df['BB_Upper'] = df['BB_Middle'] + 2 * df['BB_Std']
    df['BB_Lower'] = df['BB_Middle'] - 2 * df['BB_Std']
    df['BB_Position'] = (df['close'] - df['BB_Lower']) / (df['BB_Upper'] - df['BB_Lower'])

    # ATR
    high_low = df['high'] - df['low']
    high_close = (df['high'] - df['close'].shift()).abs()
    low_close = (df['low'] - df['close'].shift()).abs()
    tr = pd.concat([high_low, high_close, low_close], axis=1).max(axis=1)
    df['ATR'] = tr.rolling(14).mean()

    return df

def calculate_sharpe_ratio(returns, risk_free_rate=0.04, periods_per_year=252):
    """
    計算夏普比率

    注意: risk_free_rate 應根據當前市場調整
    - 2020-2021: ~0%（接近零利率）
    - 2024-2025: ~4-5%（美聯儲加息後）
    """
    excess_returns = returns - risk_free_rate / periods_per_year
    return np.sqrt(periods_per_year) * excess_returns.mean() / returns.std()
```
