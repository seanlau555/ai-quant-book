# 背景知識：加密貨幣交易特點

> 加密貨幣市場與傳統金融市場有顯著差異。理解這些特點是開發加密貨幣量化策略的前提。

---

## 一、市場特點概覽

| 特點 | 加密貨幣 | 傳統股票 |
|-----|---------|---------|
| 交易時間 | 24/7/365 | 工作日固定時段 |
| 波動率 | 高（日波動通常 2-8%，極端時可達 20%+） | 較低（日波動 0.5-2%） |
| 監管 | 弱/混亂 | 嚴格 |
| 做空 | 容易（永續合約） | 需要融券 |
| 槓桿 | 高達 125x | 通常 2-4x |
| 市場效率 | 低（套利機會多） | 高 |

## 二、24/7 交易的影響

### 2.1 優勢

- **無隔夜風險定義**：沒有傳統意義的"隔夜"
- **即時反應**：新聞發佈後可立即交易
- **更多機會**：時間長 = 機會多

### 2.2 挑戰

- **永無休止**：無法完全離開市場
- **流動性波動**：亞洲、歐洲、美洲時段流動性差異大
- **運維壓力**：系統需要 24/7 在線

### 2.3 流動性時段分佈

```
UTC 時間    主導市場    流動性
00:00-08:00  亞洲       中
08:00-16:00  歐洲       高
16:00-24:00  美洲       最高
週末         -          低
```

**策略建議**：
```python
def get_liquidity_multiplier(hour_utc, is_weekend):
    if is_weekend:
        return 0.5  # 週末流動性減半
    if 16 <= hour_utc < 24:
        return 1.2  # 美盤時段最佳
    elif 8 <= hour_utc < 16:
        return 1.0  # 歐盤時段正常
    else:
        return 0.7  # 亞盤時段較低
```

```python
# 加密貨幣波動率估算需要更短窗口
```

## 五、衍生品市場

### 5.1 永續合約

**特點**：
- 無到期日
- 資金費率機制
- 高槓杆（最高 125x）

**資金費率**：
```
資金費率 > 0 → 多頭付費給空頭 → 市場偏多
資金費率 < 0 → 空頭付費給多頭 → 市場偏空

資金費率策略：
- 做空高正費率合約 + 現貨對沖 = 賺取費率
```

### 5.2 交割合約

- 有到期日（週、月、季度）
- 期現價差存在套利機會

### 5.3 期權

- 發展較晚
- 主要在 Deribit、OKX
- 隱含波動率極高

## 六、DeFi 量化

### 6.1 AMM 機制

**Uniswap 公式**：
```
x * y = k

x = Token A 數量
y = Token B 數量
k = 常數

價格 = y / x
```

**滑點計算**：
```python
def calculate_amm_slippage(amount_in, reserve_in, reserve_out, fee=0.003):
    amount_with_fee = amount_in * (1 - fee)
    amount_out = (reserve_out * amount_with_fee) / (reserve_in + amount_with_fee)

    spot_price = reserve_out / reserve_in
    actual_price = amount_out / amount_in
    slippage = (spot_price - actual_price) / spot_price

    return slippage
```

## 八、量化策略適配

### 8.1 高頻策略

**挑戰**：
- 延遲：交易所 API 延遲 10-100ms
- 競爭：專業做市商
- 成本：手續費吃掉利潤

**建議**：除非有基礎設施優勢，否則不建議

### 8.2 中低頻策略

**適合**：
- 趨勢跟隨（1小時-日線）
- 動量策略
- 資金費率套利
- 期現套利

**示例：資金費率套利**
```python
def funding_rate_arbitrage(funding_rate, threshold=0.0003):
    """
    當資金費率 > 0.03%（每8小時）時考慮套利

    注意：資金費率通常在 -0.03% 到 +0.03% 之間
    極端情況（如 2021 年牛市）可達 0.1% - 1%

    策略：
    1. 做空永續合約
    2. 做多現貨對沖
    3. 每 8 小時收取資金費率
    """
    if funding_rate > threshold:
        gross_apr = funding_rate * 3 * 365  # 年化毛收益
        # 實際需扣除：交易手續費、借幣利息、價差成本（約30-50%）
        return {
            'perp': 'SHORT',
            'spot': 'LONG',
            'gross_apr': f'{gross_apr:.1%}',
            'note': '需扣除手續費、借幣成本、價差等'
        }
    return None
```

> **典型費率範圍**：正常市場 ±0.01%/8h；多頭擁擠時 0.05-0.1%/8h；極端情況 >0.3%/8h。

### 8.3 網格策略

**特點**：
- 在價格區間內設置多個買賣單
- 利用波動賺取價差
- 適合震盪市場

**示例**：
```python
def create_grid(lower, upper, grids, total_amount):
    grid_size = (upper - lower) / grids
    order_amount = total_amount / grids

    orders = []
    for i in range(grids):
        price = lower + i * grid_size
        orders.append({
            'price': price,
            'amount': order_amount,
            'side': 'BUY'
        })
        orders.append({
            'price': price + grid_size,
            'amount': order_amount,
            'side': 'SELL'
        })
    return orders
```

## 九、風險管理

### 9.1 特殊風險

| 風險 | 描述 | 應對 |
|-----|------|-----|
| 交易所風險 | 交易所倒閉/被黑 | 分散資金 |
| 極端波動 | 單日 50%+ 波動 | 降低槓桿 |
| 流動性枯竭 | 極端行情無法成交 | 預留緩衝 |
| 監管風險 | 政策突變 | 關注新聞 |
| 操縱風險 | 莊家控盤 | 選擇主流幣 |

### 9.2 槓桿建議

| 經驗水平 | 建議槓桿 |
|---------|---------|
| 新手 | 1x（不用槓桿） |
| 有經驗 | 2-3x |
| 專業 | 5-10x |
| 絕不建議 | > 20x |

### 9.3 風控代碼

```python
class CryptoRiskManager:
    def __init__(self):
        self.max_position_pct = 0.1   # 單一持倉不超過 10%
        self.max_leverage = 3         # 最大槓桿
        self.max_daily_loss = 0.05    # 日最大虧損 5%
        self.stop_loss = 0.02         # 單筆止損 2%

    def check_order(self, order, portfolio):
        # 檢查倉位限制
        if order.value / portfolio.total > self.max_position_pct:
            return False, "超過單一持倉限制"

        # 檢查槓桿
        if order.leverage > self.max_leverage:
            return False, "超過槓桿限制"

        # 檢查日虧損
        if portfolio.daily_pnl < -self.max_daily_loss:
            return False, "已達到日虧損限制"

        return True, "通過"
```

## 十、實踐建議

### 10.1 入門路徑

1. **學習基礎**：理解區塊鏈、錢包、交易所
2. **小額實踐**：用小資金熟悉交易流程
3. **回測驗證**：用歷史數據驗證策略
4. **模擬交易**：用測試網或模擬盤
5. **小額實盤**：逐步增加資金

### 10.2 工具推薦

| 用途 | 工具 |
|-----|------|
| API 封裝 | CCXT（統一接口） |
| 回測 | Freqtrade, VectorBT |
| 數據 | CoinGecko API, Binance API |
| 鏈上分析 | Glassnode, Dune Analytics |

### 10.3 避坑指南

1. **不要用高槓杆**：血的教訓太多
2. **不要追漲殺跌**：波動大不代表機會多
3. **不要忽視手續費**：高頻交易成本累積快
4. **不要 All In**：分散投資，控制倉位
5. **不要忽視安全**：私鑰、API 密鑰保管好

---

> **核心原則**：加密貨幣市場波動大、機會多，但風險也大。保守的倉位管理和嚴格的風控是生存的關鍵。活得久比賺得多更重要。
