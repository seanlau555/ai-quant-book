# 背景知識：加密貨幣交易特點

> 加密貨幣市場與傳統金融市場有顯著差異。了解這些特點，是開發 crypto 量化策略的先決條件。

---

## 1. 市場特點概覽

| 特點 | 加密貨幣 | 傳統股票 |
|----------------|----------------|-------------------|
| 交易時間 | 24/7/365 | 工作日固定時段 |
| Volatility | 高（通常每日 2-8%，極端事件可超過 20%） | 較低（每日 1-3%） |
| 監管 | 薄弱/混亂 | 嚴格 |
| 沽空 | 容易（perpetual contract） | 需要借貨 |
| Leverage | 最高 125x | 通常 2-4x |
| 市場效率 | 低（存在大量 arbitrage 機會） | 高 |

---

## 2. 24/7 交易的影響

### 2.1 優點

- **沒有隔夜風險的定義**：不存在傳統意義上的「隔夜」
- **即時反應**：消息公布後可立即交易
- **更多機會**：更多時間 = 更多機會

### 2.2 挑戰

- **永不停歇**：無法完全離開市場
- **Liquidity 波動**：亞洲、歐洲、美洲時段之間有顯著差異
- **運維壓力**：系統需要 24/7 在線

### 2.3 各時段的 Liquidity 分佈

```
UTC Time     Dominant Market    Liquidity
00:00-08:00  Asia               Medium
08:00-16:00  Europe             High
16:00-24:00  Americas           Highest
Weekend      -                  Low
```

**策略建議**：
```python
def get_liquidity_multiplier(hour_utc, is_weekend):
    if is_weekend:
        return 0.5  # Weekend liquidity halved
    if 16 <= hour_utc < 24:
        return 1.2  # US session best
    elif 8 <= hour_utc < 16:
        return 1.0  # Europe session normal
    else:
        return 0.7  # Asia session lower
```

### 3.2 Volatility 建模

傳統 GARCH model 需要調整：
```python
# Crypto volatility estimation needs shorter window
def crypto_volatility(returns, window=24):  # 24-hour window
    return returns.rolling(window).std() * np.sqrt(365 * 24)  # Annualized
```

## 5. 衍生品市場

### 5.1 Perpetual Contract

**特點**：
- 沒有到期日
- Funding rate 機制
- 高 leverage（最高 125x）

**Funding Rate**：
```
Funding Rate > 0 → Longs pay shorts → Market bullish
Funding Rate < 0 → Shorts pay longs → Market bearish

Funding Rate Strategy:
- Short high positive rate contracts + Long spot hedge = Earn funding rate
```

### 5.2 季度期貨

- 設有到期日（每週、每月、每季）
- Basis spread 帶來 arbitrage 機會

### 5.3 期權

- 發展較晚
- 主要在 Deribit、OKX
- Implied volatility 極高

## 6. DeFi 量化交易

### 6.1 AMM 機制

**Uniswap 公式**：
```
x * y = k

x = Token A quantity
y = Token B quantity
k = Constant

Price = y / x
```

**Slippage 計算**：
```python
def calculate_amm_slippage(amount_in, reserve_in, reserve_out, fee=0.003):
    amount_with_fee = amount_in * (1 - fee)
    amount_out = (reserve_out * amount_with_fee) / (reserve_in + amount_with_fee)

    spot_price = reserve_out / reserve_in
    actual_price = amount_out / amount_in
    slippage = (spot_price - actual_price) / spot_price

    return slippage
```

## 8. 量化策略的適應

### 8.1 高頻策略

**挑戰**：
- Latency：交易所 API latency 為 10-100ms
- 競爭：專業 market maker
- 成本：手續費侵蝕利潤

**建議**：除非你具備基礎設施優勢，否則不建議

### 8.2 中低頻策略

**適合**：
- Trend following（1 小時至日線）
- Momentum 策略
- Funding rate arbitrage
- Cash-and-carry arbitrage

**例子：Funding Rate Arbitrage**

> **典型 Funding Rate 範圍**：
> - 正常：±0.01%/8h（±0.0001）
> - 擠擁交易：0.05-0.1%/8h（0.0005-0.001）
> - 極端情緒：>0.3%/8h（>0.003）

```python
def funding_rate_arbitrage(funding_rate, threshold=0.0003):
    """
    When funding rate > 0.03% (0.0003):
    1. Short perpetual contract
    2. Long spot to hedge
    3. Collect funding rate every 8 hours

    Note: 0.03%/8h = ~33% annualized, accounting for costs
    """
    if funding_rate > threshold:
        return {
            'perp': 'SHORT',
            'spot': 'LONG',
            'expected_return': funding_rate * 3 * 365  # Annualized
        }
    return None
```

### 8.3 Grid Trading

**特點**：
- 在價格區間內設置多張買入/賣出訂單
- 透過捕捉 spread，從 volatility 中獲利
- 適合震盪市

**例子**：
```python
def create_grid(lower, upper, grids, total_amount):
    grid_size = (upper - lower) / grids
    order_amount = total_amount / grids

    orders = []
    for i in range(grids):
        price = lower + i * grid_size
        orders.append({
            'price': price,
            'amount': order_amount,
            'side': 'BUY'
        })
        orders.append({
            'price': price + grid_size,
            'amount': order_amount,
            'side': 'SELL'
        })
    return orders
```

## 9. 風險管理

### 9.1 特殊風險

| 風險 | 說明 | 應對 |
|------|-------------|----------|
| 交易所風險 | 交易所倒閉/被黑客入侵 | 分散資金 |
| 極端 Volatility | 單日 50%+ 波動 | 降低 leverage |
| Liquidity 枯竭 | 極端情況下無法成交 | 預留緩衝 |
| 監管風險 | 政策突然改變 | 留意新聞 |
| 操縱風險 | 鯨魚控制市場 | 選擇主流幣 |

### 9.2 Leverage 建議

| 經驗水平 | 建議 Leverage |
|------------------|---------------------|
| 初學者 | 1x（不用 leverage） |
| 有經驗者 | 2-3x |
| 專業人士 | 5-10x |
| 絕不建議 | > 20x |

### 9.3 風險控制代碼

```python
class CryptoRiskManager:
    def __init__(self):
        self.max_position_pct = 0.1   # Single position max 10%
        self.max_leverage = 3         # Max leverage
        self.max_daily_loss = 0.05    # Max daily loss 5%
        self.stop_loss = 0.02         # Per-trade stop loss 2%

    def check_order(self, order, portfolio):
        # Check position limit
        if order.value / portfolio.total > self.max_position_pct:
            return False, "Exceeds single position limit"

        # Check leverage
        if order.leverage > self.max_leverage:
            return False, "Exceeds leverage limit"

        # Check daily loss
        if portfolio.daily_pnl < -self.max_daily_loss:
            return False, "Daily loss limit reached"

        return True, "Passed"
```

## 10. 實踐建議

### 10.1 入門路徑

1. **學習基礎**：了解 blockchain、錢包、交易所
2. **小規模練習**：用小額資金熟習交易流程
3. **Backtest 驗證**：用歷史數據驗證策略
4. **Paper trading**：使用 testnet 或模擬帳戶
5. **小額實盤**：逐步增加資金

### 10.2 推薦工具

| 用途 | 工具 |
|---------|------|
| API Wrapper | CCXT（統一接口） |
| Backtesting | Freqtrade、VectorBT |
| 數據 | CoinGecko API、Binance API |
| On-chain 分析 | Glassnode、Dune Analytics |

### 10.3 避坑指南

1. **不要用高 leverage**：血的教訓太多
2. **不要追高殺低**：高 volatility 不等於更多機會
3. **不要忽視手續費**：高頻交易的成本累積得很快
4. **不要全倉押注**：分散投資，控制倉位大小
5. **不要忽視安全**：保護好私鑰及 API key

---

> **核心原則**：Crypto 市場 volatility 高、機會多，但風險同樣高。保守的倉位管理與嚴格的風險控制，是生存的關鍵。活得長久比賺得多更重要。
