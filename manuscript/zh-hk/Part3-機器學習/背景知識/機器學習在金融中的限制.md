# 背景知識：機器學習在金融中的限制

> 「如果 deep learning 能預測股價，為甚麼頂級 AI 公司不是全部都在做量化交易？」

---

## 核心限制：極低的信噪比

| 領域 | 信噪比 | 可達到的準確率 |
|--------|----------------------|---------------------|
| 圖像識別 | 高 | 95%+ |
| 語音識別 | 高 | 90%+ |
| 自然語言 | 中 | 80%+ |
| **股價預測** | **極低** | **52-55% 已屬頂級水平** |

**為甚麼金融的信噪比這麼低？**

1. **市場近乎有效**：明顯的規律很快就被套利掉
2. **參與者眾多**：你找到的規律，別人也在用
3. **噪音主導**：短期價格波動有 90% 是隨機波動
4. **Reflexivity**：預測本身會改變被預測的對象

---

## 限制 1：數據不足

Deep learning 需要大量數據，但金融數據有限。

| 數據類型 | 樣本數量 | 適合 deep learning 嗎 |
|-----------|-------------|---------------------------|
| 20 年日線數據 | 5,000 筆 | 遠遠不夠 |
| 5 年分鐘數據 | 500,000 筆 | 勉強可用 |
| 1 年 tick 數據 | 數百萬筆 | 可以嘗試 |

**對比**：ImageNet 有 1,400 萬張圖像，GPT 以數以萬億計的 token 訓練。

---

## 限制 2：分佈不穩定

訓練數據與預測數據的分佈不同（Regime Shift）。

```
Training Set (2015-2019):
  - Bull market mostly
  - Volatility 15%
  - VIX average 15

Test Set (2020):
  - COVID crash
  - Volatility spiked to 80%
  - VIX peak 82

-> Model completely fails
```

**Deep learning 的假設**：訓練數據與測試數據來自相同的分佈。金融市場違反這個假設。

---

## 限制 3：容易 overfitting

金融數據中的「規律」可能只是噪音。

| 模型複雜度 | 訓練集表現 | 測試集表現 | 診斷 |
|------------------|-------------------------|---------------------|-----------|
| 簡單線性模型 | 年化 8% | 年化 6% | 正常 |
| Random Forest | 年化 25% | 年化 8% | 輕微 overfitting |
| LSTM | 年化 80% | 年化 -5% | 嚴重 overfitting |
| Transformer | 年化 150% | 年化 -15% | 災難性 overfitting |

**複雜模型不等於更好的預測**；在金融中，往往相反。

---

## 限制 4：預測不等於獲利

52% 的準確率聽起來比隨機好，但扣除成本後可能蝕錢。

```
Assumptions:
  - Prediction accuracy 52%
  - Each win 1%, each loss 1%
  - Trading cost 0.3%

Expected return = 52% x 1% - 48% x 1% - 0.3%
               = 0.52% - 0.48% - 0.3%
               = -0.26% (losing money!)

Required win/loss ratio:
  Win 1.5%, lose 1%
  -> 52% x 1.5% - 48% x 1% - 0.3% = 0.28% (small profit)
```

---

## 限制 5：可解釋性差

Deep learning 是黑箱；金融監管和風險控制需要解釋。

| 場景 | 線性模型 | Deep learning |
|----------|--------------|---------------|
| 為甚麼買這隻股票？ | 「Momentum 因子得分高」 | 「Network output 0.7」 |
| 虧損歸因 | 「Value 因子失效」 | 不知道 |
| 監管解釋 | 可以提供 | 困難 |
| 風險控制調整 | 調整單一因子 | 需要 retraining |

---

## 限制 6：硬件與成本

訓練 deep 模型需要大量運算力；量化回報未必能覆蓋成本。

| 資源 | 成本 | 所需回報 |
|----------|------|-----------------|
| GPU cluster 訓練 | $10,000+/月 | 年化 > 10% |
| 數據購買 | $50,000+/年 | 年化 > 5% |
| 人才成本 | $200,000+/年 | 年化 > 20% |

**對比**：一個簡單的 moving average 策略，成本接近零。

---

## ML 究竟甚麼時候有效？

| 場景 | ML 的效果 | 原因 |
|----------|------------------|--------|
| 高頻交易 | 有限 | Latency 比模型更重要 |
| 每日選股 | 可用 | 數據足夠，複雜度適中 |
| 每月資產配置 | 有限 | 數據太少 |
| 另類數據挖掘 | 有價值 | 處理非結構化數據 |
| 風險建模 | 有價值 | 預測 volatility 比預測回報容易 |

---

## 實務建議

### 1. 簡單模型優先
```
First choice: Linear regression, Ridge regression, Logistic regression
Second: Random Forest, XGBoost
Last: LSTM, Transformer
```

### 2. Validation 重於模型
```
Spend 80% of time on validation:
- Walk-Forward validation
- Multi-period stability
- Return after costs
```

### 3. Feature 重於模型
```
80% of Alpha comes from feature engineering
20% from model selection

Good features + Simple model > Poor features + Complex model
```

### 4. 預測 volatility 而非回報
```
Volatility is easier to predict:
- Volatility has clustering effect
- Volatility autocorrelation 0.7-0.9
- Return autocorrelation ≈ 0

Use ML to predict volatility -> Use rules to trade
```

---

## 總結

| 限制 | 影響 | 應對策略 |
|------------|--------|-----------------|
| 低信噪比 | 準確率難以超過 55% | 降低期望 |
| 數據不足 | 容易 overfitting | 簡化模型 |
| 分佈 drift | 模型失效 | Rolling retraining |
| 成本高 | 回報被蠶食 | 降低 turnover |
| 黑箱 | 難以做風險控制 | 保持可解釋性 |

**核心結論**：ML 在量化中的價值是**訊號增強（signal enhancement）**，而不是**預測價格走勢**。
