# 背景知識：Multi-Agent 框架對比

> Multi-agent 系統正成為複雜 AI 應用的標準架構。本文比較主流框架的特點與適用場景。

---

## 2. 框架詳情

### 2.1 Shannon

**定位**：Production-grade multi-agent orchestration 平台

**核心特點**：
- Go + Rust + Python 多語言架構
- Temporal workflow engine（deterministic replay）
- 內置預算控制與成本追蹤
- WASI sandbox 執行
- OPA policy engine

**架構**：
```
Orchestrator (Go)     → Task routing, budget control
Agent Core (Rust)     → Sandbox execution
LLM Service (Python)  → Model calls, tool execution
Temporal              → Workflow orchestration
```

**適用場景**：
- Production 環境部署
- 有成本控制需求
- 需要 deterministic debugging
- 需要安全隔離

**示例**：
```bash
curl -X POST http://localhost:8080/api/v1/tasks \
  -d '{"query": "Analyze market data", "session_id": "quant-1"}'
```

---

### 2.2 AutoGen

**定位**：Microsoft 開源的對話式 multi-agent 框架

**核心特點**：
- 基於對話的 Agent 互動
- 支援 human-in-the-loop
- 代碼執行能力
- 靈活的 Agent 定義

**架構**：
```
UserProxyAgent    → Represents user, can execute code
AssistantAgent    → LLM-powered assistant
GroupChat         → Multi-Agent conversation management
```

**適用場景**：
- 研究與 prototyping
- 代碼生成任務
- 人機協作需求
- 對話式 workflow

**示例**：
```python
from autogen import AssistantAgent, UserProxyAgent

assistant = AssistantAgent("assistant", llm_config=llm_config)
user_proxy = UserProxyAgent("user_proxy", code_execution_config={"work_dir": "coding"})

user_proxy.initiate_chat(assistant, message="Analyze this dataset")
```

---

### 2.3 CrewAI

**定位**：角色扮演式 multi-agent 協作框架

**核心特點**：
- 清晰的角色定義（Role、Goal、Backstory）
- 任務驅動
- 工具整合
- 簡單易用

**架構**：
```
Agent    → Define roles and capabilities
Task     → Define specific tasks
Crew     → Organize Agent collaboration
Tool     → Available tools for Agents
```

**適用場景**：
- 快速 prototyping
- 角色分明的任務
- 內容生成
- 研究助手

**示例**：
```python
from crewai import Agent, Task, Crew

researcher = Agent(
    role='Market Researcher',
    goal='Analyze market trends',
    backstory='You are a senior quantitative analyst'
)

task = Task(
    description='Analyze BTC trends over the past week',
    agent=researcher
)

crew = Crew(agents=[researcher], tasks=[task])
result = crew.kickoff()
```

---

### 2.4 LangGraph

**定位**：圖結構的 Agent workflow 框架

**核心特點**：
- 狀態機 + 圖結構
- 支援循環與分支
- 整合 LangChain 生態
- Workflow 可視化

**架構**：
```
StateGraph   → Define states and transitions
Node         → Processing nodes (functions or Agents)
Edge         → State transition logic
Checkpointer → State persistence
```

**適用場景**：
- 複雜 workflow
- 有循環邏輯的需求
- 需要狀態管理
- LangChain 用戶

**示例**：
```python
from langgraph.graph import StateGraph

workflow = StateGraph(AgentState)
workflow.add_node("analyze", analyze_market)
workflow.add_node("decide", make_decision)
workflow.add_edge("analyze", "decide")

app = workflow.compile()
result = app.invoke({"input": "Analyze market"})
```

---

### 2.5 MetaGPT

**定位**：用於軟件開發的 multi-agent 系統

**核心特點**：
- 模擬軟件團隊
- 角色：PM、Architect、Engineer、QA
- 文檔驅動開發
- 代碼生成

**架構**：
```
ProductManager → Requirements analysis
Architect      → System design
Engineer       → Code implementation
QA             → Testing and validation
```

**適用場景**：
- 軟件開發任務
- 代碼生成
- 技術文檔生成

## 4. 量化交易場景適配

### 4.1 場景：市場分析 Multi-Agent

| 框架 | 實現難度 | 推薦度 |
|-----------|---------------------------|----------------|
| Shannon | 中 | 5/5 |
| AutoGen | 低 | 4/5 |
| CrewAI | 低 | 3/5 |
| LangGraph | 中 | 4/5 |

### 4.2 場景：實時交易 Execution

| 框架 | 實現難度 | 推薦度 |
|-----------|---------------------------|----------------|
| Shannon | 中 | 5/5 |
| AutoGen | 高 | 2/5 |
| CrewAI | 高 | 1/5 |
| LangGraph | 中 | 3/5 |

**原因**：
- Shannon 具備 production-grade orchestration 和安全 sandbox
- AutoGen/CrewAI 缺乏 execution 控制
- 實時交易需要低 latency 和高可靠性

### 4.3 場景：策略研究 Prototyping

| 框架 | 實現難度 | 推薦度 |
|-----------|---------------------------|----------------|
| Shannon | 中 | 3/5 |
| AutoGen | 低 | 5/5 |
| CrewAI | 低 | 4/5 |
| LangGraph | 中 | 4/5 |

**原因**：研究階段需要快速迭代，易用性更重要

## 6. 整合示例

### 6.1 Shannon + 量化策略

```python
from shannon import ShannonClient

client = ShannonClient(base_url="http://localhost:8080")

# Submit analysis task
handle = client.submit_task(
    query="Analyze BTC/USDT market state, determine if trending or ranging",
    session_id="regime-detection"
)

# Wait for result
result = client.wait(handle.task_id)
```

### 6.2 AutoGen + 量化研究

```python
from autogen import AssistantAgent, UserProxyAgent

quant_analyst = AssistantAgent(
    "quant_analyst",
    system_message="You are a quantitative analyst skilled in market data analysis and strategy design",
    llm_config=llm_config
)

user = UserProxyAgent(
    "user",
    code_execution_config={"work_dir": "research"}
)

user.initiate_chat(
    quant_analyst,
    message="Design an RSI-based mean reversion strategy"
)
```

### 6.3 CrewAI + 研究團隊

```python
from crewai import Agent, Task, Crew

analyst = Agent(
    role='Quant Analyst',
    goal='Analyze market data',
    tools=[market_data_tool]
)

developer = Agent(
    role='Strategy Developer',
    goal='Convert analysis into code',
    tools=[code_execution_tool]
)

reviewer = Agent(
    role='Risk Control Reviewer',
    goal='Check strategy risks',
    tools=[risk_analysis_tool]
)

crew = Crew(
    agents=[analyst, developer, reviewer],
    tasks=[...],
    process="sequential"
)
```

## 7. 未來趨勢

1. **標準化**：Agent 通訊協議標準
2. **專業化**：特定領域的垂直框架
3. **Production-Ready**：更多框架支援 production 部署
4. **整合**：多框架整合成為常態
5. **Low-Code**：可視化的 Agent orchestration 工具

---

## 8. 選擇建議

| 場景 | 推薦框架 | 原因 |
|----------|----------------------|--------|
| 量化實盤交易 | Shannon | Production-grade、成本控制、安全 |
| 量化策略研究 | AutoGen | 易用、可執行代碼 |
| 快速 prototyping | CrewAI | 最簡單、角色清晰 |
| 複雜 workflow | LangGraph | 圖結構、狀態管理 |
| 代碼生成 | AutoGen / MetaGPT | 專門優化 |

---

> **核心原則**：沒有完美的框架，只有適合你場景的選擇。研究時用簡單的框架快速驗證，production 時用穩健的框架可靠運行。
